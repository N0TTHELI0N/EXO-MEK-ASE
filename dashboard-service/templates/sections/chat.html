Setup (run in Discord, Admin only):
1️⃣ /chat-bridge-enable enabled:true
2️⃣ /chat-bridge-channel channel:#chat-log — one-way log
3️⃣ /chat-bridge-relay channel:#game-bridge — two-way relay (optional)
4️⃣ /chat-bridge-toggle game_to_discord:true discord_to_game:true — control direction
Send a message into the game from Discord with /chat-bridge-send or by typing in the relay channel.
Auto-detect punishments below run only while the bridge is enabled.
